# Инструкция по добавлению логотипа

## Что нужно сделать:

1. Сохраните файл логотипа I-PEPTIDES (с розовым символом и текстом) как:
   ```
   /home/user/i-peptides/public/logo.png
   ```

2. Рекомендуемые параметры изображения:
   - Формат: PNG с прозрачным фоном
   - Размер: примерно 600x150 пикселей
   - Разрешение: 2x для Retina дисплеев

3. После добавления файла логотип автоматически появится:
   - В шапке сайта (header)
   - В футере (footer)

## Текущее состояние:

✅ Код интегрирован в:
- `/components/SiteHeader.tsx`
- `/components/Footer.tsx`

❌ Требуется: файл изображения `/public/logo.png`
