# i-peptides (template)

Blue/white scalable template for:
- E-commerce: catalog, product pages, cart (local), checkout placeholder
- Knowledge base: peptide profiles + links to products
- Global search (demo)

## Notes
- All peptide/product texts are placeholders. Replace with your verified copy.
- Add Auth (NextAuth), DB (PostgreSQL + Prisma), and payments (Stripe) when ready.

## Quick start
1) `npm i`
2) `npm run dev`
